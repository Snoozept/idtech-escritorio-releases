# IDtech — APKs de teste

APKs de teste da app **IDtech**. O código-fonte está **privado** (`Snoozept/idtech-escritorio`).

## Como instalar / actualizar
1. Descarrega o APK mais recente em [Releases](https://github.com/Snoozept/idtech-escritorio-releases/releases) ou usa o manifesto [`latest.json`](./latest.json).
2. No telemóvel, permite instalação de fontes desconhecidas se o Android pedir.
3. **Primeira instalação com a assinatura estável:** se tinhas um APK antigo (assinatura de debug do CI), **desinstala** a app IDtech antes de instalar este — a assinatura mudou uma vez e o Android não permite actualizar por cima.

A app também tem **Procurar atualizações** nas definições.

## Manifesto
`latest.json` — `{ version, versionCode, apkUrl, notes }` apontando para o último build de teste.
